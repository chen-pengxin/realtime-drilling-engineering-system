## 模型含义

- 最小曲率平面圆弧：每个弯曲段由起点姿态、终点姿态和曲率确定，采用最小曲率圆弧内核；曲率为零时退化为直线。
- 恒工具面恒曲率空间曲线：每个弯曲段保持曲率和当地工具面恒定，姿态按恒工具面状态方程积分，位置用 DOP853 求积；一般不是平面圆弧。

每个组合重复 3 次，表中为中位数。总耗时还包含准备与求解器内部校验；各子项不能脱离计时边界直接求和。浏览器耗时见独立报告，本表仅为原算法工作流计时。
