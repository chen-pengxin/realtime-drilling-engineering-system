# 多源文档解析与内容展示

系统把上传文件分成“原件归档”和“内容解析”两条记录。原件按 SHA-256 保存字节和原始文件名，显示名称只用于工程资料列表；下载、历史版次和资料包仍使用该版上传时的原始文件名。解析快照写入 `drilling_document_parse`，章节写入 `drilling_document_section`，解析失败不会替换已确认的测斜版本或设计轨道。

## 支持的原件

解析器先按文件内容识别格式，再参考扩展名。因此扩展名为 `.docx` 但实际是 Word 97-2003 OLE 的文件也会按旧版 Word 读取。

| 原件 | 保存内容 |
| --- | --- |
| XLS/XLSX | 每个工作表、封皮、合并单元格、公式、数值格式、图表和图片；旧版 XLS 的工作表使用 xlrd，图形使用 LibreOffice 副本转换。 |
| DOC/DOCX/WPS/RTF | 正文段落、表格、合并关系、页眉/页脚、文本框和插图。旧版 Word 使用 Apache POI HWPF，不依赖 Office 转换。 |
| PDF | 每页原文、页码定位、可提取表格、图像页和 COMPASS Survey Report 的工具程序、磁场、靶点、套管、测斜点等工程章节。扫描页使用本机 OCR，并保留原页。 |
| TXT/CSV/无后缀文本/WITSML/XML | 原文、编码、通用表格；识别 `SURVEY LIST`、测斜工具分段和测深/井斜/方位记录。 |
| ZIP | 递归解析容器内支持的 PDF、Office、TXT、CSV、XML 等成员，章节定位带有成员路径。 |

未知的无后缀二进制会作为附件归档并显示诊断；损坏或加密的原件保留原文件并标记为待处理，不会生成虚假表格。

## 导入流程

上传接口支持单文件和最多 200 个文件的批量导入。上传时先选择区块、井场、井、井眼和资料用途（实钻测斜、设计轨道或参考资料），服务端把井眼关联、文件版次和解析版次一并保存。解析出的测斜表只作为候选记录，必须经过工程确认才可成为有效测斜版本；重新解析只追加不可变快照，既有确认版本不变。

## 内容查看

工程资料页和系统文件页的“查看内容”打开同一个内容查看器。左侧按正文、表格/工作表、插图/图表分组，中央显示完整表格或原文，支持表内查询、分页、合并单元格、原文页码和公式提示。图片、Office 图形、PDF 原页通过受限的原件定位读取，不能访问压缩包之外的路径。顶部可切换解析版次并手动重新解析。

## 当前原始数据核验

2026-11-17 使用数据库中 370 个原件（对应 371 条来源记录和 1 条参考资料记录）完成回填。结果为 370 条来源记录和 1 条参考资料记录已解析，另有 1 条来源记录保留为失败状态；内容快照共 750 个，章节 43,115 个；轨迹数据表候选和站点仍保持原有版本头不变。唯一待处理文件是 `米45-30YH5井钻井井史.doc`，其 OLE 扇区结构在原件中已损坏，读取器拒绝猜测内容；重新提供可正常打开的原件后可在页面点击“重新解析”。核验记录见 `docs/verification/document-content-final.json`。
